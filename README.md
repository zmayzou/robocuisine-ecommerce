# RoboCuisine E-Commerce

RoboCuisine is a modern e-commerce web application dedicated to smart kitchen robots and premium culinary accessories.

Built with Django, the platform provides a complete online shopping experience including authentication, cart management, orders, promotions, giveaways, dashboards and product management.

---

# Features

- User authentication system
- User dashboard
- Admin dashboard
- Product catalog
- Product detail pages
- Categories system
- Shopping cart
- Order management
- Promotions & discount codes
- Giveaways system
- Product reviews
- Stock management
- Responsive premium UI
- Search & filtering system

---

# Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- MySQL / SQLite
